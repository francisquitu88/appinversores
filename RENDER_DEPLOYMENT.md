# Deployment to Render

This project is ready to deploy as a Static Site on Render.

## Render Configuration

### Build Settings
- **Build Command:** `npm install && npm run build`
- **Publish Directory:** `dist`

### Environment Variables
Set these in Render dashboard under "Environment":

```
VITE_SUPABASE_URL=https://hzwywrlnkguyvarhhczt.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your_publishable_key
```

**Important:** These are public keys only (VITE_ prefix). Never add service role keys or secrets.

### SPA Routing Configuration

Render Static Sites must rewrite all undefined routes to `index.html` for client-side routing to work.

**Required:** Add a `_redirects` file in the root directory (already present if you see this note).

If Render doesn't automatically handle this, manually configure:

**Rewrite Rules:**
```
/*  /index.html  200
```

OR use Render's redirect configuration if available in UI.

## Troubleshooting

### Routes return 404

Ensure Render's Static Site has the SPA rewrite rule configured to send all requests to `index.html`.

### Environment variables not loading

Double-check in Render dashboard that `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` are set (not prefixed with anything).

### Supabase connection fails

Verify the Supabase URL and public key are correct. The app will show "Supabase configuration is missing" if they're not set.

### TypeScript or build errors

Run locally:
```bash
npm install
npm run build
```

Fix any errors before pushing to Render.
